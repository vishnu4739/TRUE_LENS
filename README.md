TrueLens is an AI-powered image authenticity detection system designed to analyze digital images and estimate whether they are original photographs or artificial intelligence (AI) generated constructs. The complete source code, featuring a full-stack architecture built with React, Node.js, and a Python-based FastAPI machine learning pipeline, is publicly hosted on the TrueLens GitHub Code Repository. To experience the system's live classification capabilities, model comparison dashboards, and user interface firsthand, please visit the TrueLens Live Web App.
